RENOVA ADMIN UPDATE

This patch adds:
- Category-first product selection in the Review Manager.
- Product selection filtered by the chosen category.
- A confirmed Delete action in the admin product catalogue.
- Deletion of associated product reviews while preserving historical orders.
- Seed protection so deleted starter products do not return after restart.

INSTALL FROM TERMINAL

1. Put Renova_Admin_Review_Delete_Update.zip in your Downloads folder.
2. Open Terminal and enter your existing Renova_Store project:

   cd ~/Documents/Renova_Store

3. Back up the four files being updated:

   mkdir -p ../Renova_Store_backup_before_admin_update
mkdir -p ../Renova_Store_backup_before_admin_update/app/components
mkdir -p ../Renova_Store_backup_before_admin_update/app/api/products
mkdir -p ../Renova_Store_backup_before_admin_update/app/lib
cp app/components/admin-catalogue.tsx ../Renova_Store_backup_before_admin_update/app/components/
cp app/api/products/route.ts ../Renova_Store_backup_before_admin_update/app/api/products/
cp app/lib/server-catalog.ts ../Renova_Store_backup_before_admin_update/app/lib/
cp app/globals.css ../Renova_Store_backup_before_admin_update/app/

4. Extract the patch into the project root:

   unzip -o ~/Downloads/Renova_Admin_Review_Delete_Update.zip -d .

5. Build and verify:

   npm run build

6. Push only after the build succeeds:

   git add app/components/admin-catalogue.tsx app/api/products/route.ts app/lib/server-catalog.ts app/globals.css
   git commit -m "Improve review manager and add product deletion"
   git push

No database migration is required.
