RENOVA ADMIN PASSWORD RECOVERY UPDATE

This focused update adds:
- Forgot password link on /admin/login
- Password-recovery request page
- Secure reset page for the Neon email link
- Responsive owner-login and recovery styling
- Server-controlled Neon recovery requests with a 15-second timeout
- Clear error feedback instead of an endless "Sending secure link" state

It does not include a database migration and does not change products, promos,
orders, checkout, Paystack, environment variables, or storefront components.

INSTALL ON MAC

1. Open Terminal and create a safety checkpoint:

cd ~/Documents/Renova_Store
git add .
git commit -m "Checkpoint before admin password recovery"

2. Extract the update into the existing project:

unzip -o ~/Downloads/Renova_Admin_Password_Recovery_2026-08-31.zip \
  -d ~/Documents/Renova_Store

3. Build locally:

cd ~/Documents/Renova_Store
npm install
npm run build

4. Push for Render deployment:

git add app/admin app/components app/globals.css
git commit -m "Add Neon admin password recovery"
git push origin migration/neon-render

5. After Render reports a successful deployment, open:

https://shoprenova.com.ng/admin/login

Click "Forgot password?", enter relixsx@gmail.com, and click "Send reset link".
Check the inbox and spam folder. Open the Neon recovery email, create the new
password, then sign in.

IMPORTANT
- Do not delete the Neon user.
- Do not select "Remove admin".
- A reset link is time-limited. Request another link if it expires.
- Neon Auth email/password recovery must be enabled for the project.
